# blog

Hardware Wrighter — hardware projects, tools, experiments, reviews, and lab notes.

## Live site

**https://hardwarewrighter.github.io/blog/**

This is the temporary address. Once DNS for `hardwarewrighter.com` is configured,
the canonical URL becomes `https://blog.hardwarewrighter.com/` and the github.io
address will redirect to it.

## Status

Placeholder. `index.html` is a static landing page standing in for the real blog.
`.github/workflows/pages.yml` copies it into `dist/` and deploys that to GitHub
Pages on every push to `main`; the build step is where a site generator goes later.
